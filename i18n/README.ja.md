# 使い捨てメールドメイン、30分ごとに再構築

<p align="center"><b>使い捨て・一時利用・捨てアドレス用のメールドメイン 219,530 件。素の一覧を1つ、24時間体制で更新しています。</b></p>
<p align="center"><sub>MITライセンス &middot; 登録不要、APIキー不要、レート制限なし &middot; 更新日 09.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/ja.svg?v=1788996636" alt="ffraud.com でアドレスを無料でチェック" width="540"></a></p>

使い捨ての受信箱は、偽アカウントが量産される経路そのものです。登録して、確認リンクを受け取り、無料枠を使い切り、また繰り返す。これは [ffraud.com](https://ffraud.com) を支えているオープンな使い捨てメールデータベースで、見つけられる限りの一時利用・使い捨てメールドメインが、1つのテキストファイルに入っています。新しい使い捨てサービスは毎日生まれるので、この一覧は**30分ごと**に再構築されます。取得したものは今この瞬間に生きているもので、先週のスナップショットではありません。登録不要、APIキー不要、レート制限なし。

## 主要な数字

- **219,530** 件の使い捨て・一時利用メールドメイン。1行に1つ、ソート済みで、そのまま `Set` に読み込めます
- **30分ごと**に再構築してプッシュ。コミット履歴がそのまま変更履歴で、[`metadata.json`](metadata.json) に正確なビルド時刻が入っています
- 検出は一覧だけに頼りません。[ffraud.com](https://ffraud.com) のエンジンは**メールインフラ**からも使い捨てサービスを見分けるので、どの一覧にも載る前、出現したその日に新しいドメインを捕まえられます
- 主要なメール事業者と有料サービスは意図的に**除外**しているので、自社ドメインを使う本物の顧客が使い捨てと取り違えられることはありません
- **MITライセンス**、商用利用可、クレジット不要
- テキストファイル1つ。アーカイブもスキーマもクライアントライブラリもありません

## ダウンロードせずに1件だけ調べる

1件調べるために一覧をダウンロードする必要はありません。公開APIはキー不要で、1日の上限もありません。

```bash
# 1つのIPの完全な情報：スコア、理由、カテゴリ
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# このアドレスは使い捨てか？
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# このドメインは使い捨てメールボックスを配っているか？
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

エージェントやアシスタント向け：[ffraud.com/llms.txt](https://ffraud.com/llms.txt) が機械可読インデックス、[ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) が全ドキュメントのプレーンなMarkdown、[ffraud.com/openapi.json](https://ffraud.com/openapi.json) がOpenAPI仕様です。3つとも公開されており、キー不要で、直接取得されることを前提にしています。ページで確認したい方は [ffraud.com/tools](https://ffraud.com/tools) の無料チェッカーをどうぞ。

## この一覧の作り方

2つのものが土台です。どのサービスが使い捨てメールボックスを配っているかを見張っている自前のハニーポット観測網と、登録フォームを悪用された人たちからの報告です。候補となるドメインはすべて、公開前に ffraud エンジンが検証しています。

エンジンはドメイン名だけでなく、**その背後にあるメールインフラ**からも使い捨てサービスを見分けます。この手のサービスの運営者は新しいドメインを買い続けますが、同じ一握りのメールサーバーに向け続けるので、まっさらな新ドメインでも出現したその日に見分けられます。どの一覧に載るよりも何週間も早くです。

本物の企業をこの一覧から遠ざけているのも、同じ考え方です。一般向けのメールプラットフォームは、Google Workspace や Microsoft 365 から IONOS、Strato、GMX、Proton、Zoho、iCloud まで名指しで除外しています。使い捨てサービスが100万人の本物の顧客の隣にドメインを置いたところで、その顧客について何も語らないからです。ここで慎重にすると検出をいくつか取り逃がします。雑にやれば、誰かが本物の登録を1件失います。

## よくある質問

<details>
<summary><b>実際にどのくらいの頻度で更新されますか？</b></summary>

30分ごとです。稼働中のエンジンから再構築してここにプッシュしています。このリポジトリのコミット一覧が正直な記録で、[`metadata.json`](metadata.json) に手元のコピーの正確なUTCビルド時刻が入っています。

</details>

<details>
<summary><b>商用製品で使えますか？</b></summary>

使えます。MITで、クレジット不要、別途の商用ライセンスもなく、誰かに許可を取る必要もありません。

</details>

<details>
<summary><b>Gmail や Proton、顧客の自社ドメインまでブロックしてしまいませんか？</b></summary>

しません。個人向け・法人向けの主要なメール事業者は意図的に除外していますし、他人のドメインのメールを預かるプラットフォームも同様です。この一覧に入るのは使い捨てサービスだけです。

</details>

<details>
<summary><b>載っていないドメインがあります。追加できますか？</b></summary>

ぜひお願いします。[ffraud.com/report](https://ffraud.com/report) から報告するか、ここで issue を立ててください。検証のうえ、確認できたドメインは次のビルド、30分以内に反映されます。

</details>

<details>
<summary><b>まっとうなドメインが載っています。どうすれば外れますか？</b></summary>

[ffraud.com/report](https://ffraud.com/report) からドメインを添えて知らせてください。誤検出は高くつく種類の間違いで、私たちもそう扱っています。確認できたものは次のビルドで解除されます。

</details>

<details>
<summary><b>1件ずつ調べるAPIはありますか？</b></summary>

あります。キーも不要です。上のセクション、または [ffraud.com/tools/email-blacklist-check](https://ffraud.com/tools/email-blacklist-check) の無料チェッカーをどうぞ。

</details>
