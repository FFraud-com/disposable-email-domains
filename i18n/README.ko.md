# 일회용 이메일 도메인, 30분마다 재생성

<p align="center"><b>일회용, 임시, 쓰고 버리는 이메일 도메인 219,466개. 단순한 목록 하나를 24시간 갱신합니다.</b></p>
<p align="center"><sub>MIT 라이선스 &middot; 가입 불필요, API 키 불필요, 요청 제한 없음 &middot; 업데이트 08.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/ko.svg?v=1788843679" alt="ffraud.com에서 주소를 무료로 검사" width="540"></a></p>

임시 메일함은 가짜 계정이 대량으로 만들어지는 바로 그 경로입니다. 가입하고, 확인 링크를 받고, 무료 한도를 태우고, 반복합니다. 이것은 [ffraud.com](https://ffraud.com)을 떠받치는 공개 일회용 이메일 데이터베이스로, 저희가 찾을 수 있는 모든 임시·일회용 메일 도메인이 하나의 텍스트 파일에 담겨 있습니다. 새 일회용 서비스는 매일 생기기 때문에 이 목록은 **30분마다** 다시 만들어집니다. 받아 가는 것은 지금 살아 있는 것이지 지난주의 스냅숏이 아닙니다. 가입도, API 키도, 요청 제한도 없습니다.

## 핵심 수치

- 일회용·임시 이메일 도메인 **219,466개**. 한 줄에 하나, 정렬되어 있어 `Set`에 바로 넣을 수 있습니다
- **30분마다** 다시 만들어 푸시합니다. 커밋 기록이 곧 변경 기록이고, [`metadata.json`](metadata.json)에 정확한 빌드 시각이 있습니다
- 탐지는 이 목록에서 끝나지 않습니다. [ffraud.com](https://ffraud.com)의 엔진은 **메일 인프라**로도 일회용 서비스를 알아보기 때문에, 어떤 목록에도 오르기 전, 등장한 그날 새 도메인을 잡아냅니다
- 주요 메일 제공사와 유료 서비스는 의도적으로 **제외**되어 있어, 자기 도메인을 쓰는 실제 고객이 일회용으로 오인되는 일은 없습니다
- **MIT 라이선스**, 상업적 이용 포함, 출처 표기 불필요
- 텍스트 파일 하나. 압축도, 스키마도, 클라이언트 라이브러리도 없습니다

## 빠른 시작

```bash
# 목록 전체, 한 줄에 도메인 하나
curl -s https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/disposable-email-domains.txt
```

`Set`에 읽어 넣고 가입 단계에서 주소의 도메인 부분을 거절하세요. 이 정도 규모면 메모리 조회는 비용이 없다시피 하고, 일회용 계정이 데이터베이스에 닿기 전에 막힙니다.

## 내려받지 않고 하나만 조회하기

주소 하나 확인하려고 목록을 내려받을 필요는 없습니다. 공개 API는 키가 필요 없고 일일 상한도 없습니다.

```bash
# IP 하나의 전체 정보: 점수, 근거, 분류
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# 이 주소는 일회용인가?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# 이 도메인이 임시 메일함을 나눠주는가?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

에이전트와 어시스턴트를 위한 안내: [ffraud.com/llms.txt](https://ffraud.com/llms.txt)가 기계용 색인, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt)가 모든 문서의 순수 마크다운 버전, [ffraud.com/openapi.json](https://ffraud.com/openapi.json)이 OpenAPI 명세입니다. 셋 다 공개되어 있고 키가 필요 없으며, 직접 가져가라고 만든 것입니다. 페이지가 편한 분은 [ffraud.com/tools](https://ffraud.com/tools)의 무료 검사 도구를 쓰시면 됩니다.

## 이 목록이 만들어지는 방식

두 가지가 이걸 만듭니다. 어떤 서비스가 임시 메일함을 나눠주는지 지켜보는 자체 허니팟 센서망, 그리고 가입 폼을 악용당한 사람들의 신고입니다. 후보 도메인은 모두 공개 전에 ffraud 엔진이 검증합니다.

엔진은 도메인 이름만이 아니라 **그 뒤에 있는 메일 인프라**로도 일회용 서비스를 알아봅니다. 이런 서비스의 운영자는 새 도메인을 계속 사들이면서도 늘 같은 몇 대의 메일 서버로 향하게 하기 때문에, 갓 나온 도메인도 등장한 그날 알아볼 수 있습니다. 어떤 목록에 오르기보다 몇 주 이릅니다.

같은 논리가 실제 기업을 이 목록 밖에 두는 이유이기도 합니다. 일반 대중을 상대하는 메일 플랫폼은 Google Workspace와 Microsoft 365부터 IONOS, Strato, GMX, Proton, Zoho, iCloud까지 이름으로 제외합니다. 일회용 서비스가 백만 명의 실제 고객 옆에 도메인을 세워둔다고 해서 그 고객들에 대해 말해주는 것은 없기 때문입니다. 여기서 신중하면 탐지 몇 건을 놓치지만, 부주의하면 누군가는 진짜 가입 하나를 잃습니다.

30분마다입니다. 살아 있는 엔진에서 다시 만들어 여기로 푸시합니다. 이 저장소의 커밋 목록이 정직한 기록이고, [`metadata.json`](metadata.json)에 지금 가진 사본의 정확한 UTC 빌드 시각이 있습니다.

</details>

<details>
<summary><b>상용 제품에 써도 되나요?</b></summary>

됩니다. MIT이고, 출처 표기도, 별도 상용 라이선스도, 허락받을 사람도 없습니다.

</details>

<details>
<summary><b>Gmail이나 Proton, 고객의 자체 도메인까지 막게 되나요?</b></summary>

아닙니다. 개인용·업무용 주요 메일 제공사는 의도적으로 제외했고, 남의 도메인 메일을 대신 운영하는 플랫폼도 마찬가지입니다. 이 목록에는 일회용 서비스만 들어갑니다.

</details>

<details>
<summary><b>빠진 도메인이 있습니다. 추가할 수 있나요?</b></summary>

꼭 부탁드립니다. [ffraud.com/report](https://ffraud.com/report)에 신고하거나 여기에 이슈를 열어주세요. 검증 후 확인된 도메인은 다음 빌드, 30분 안에 반영됩니다.

</details>

<details>
<summary><b>정상적인 도메인이 목록에 있습니다. 어떻게 빼나요?</b></summary>

[ffraud.com/report](https://ffraud.com/report)로 도메인과 함께 알려주세요. 오탐은 비싼 종류의 실수이고 저희도 그렇게 다룹니다. 확인된 것은 다음 빌드에서 해제됩니다.

</details>

<details>
<summary><b>주소 하나씩 조회하는 API가 있나요?</b></summary>

있고, 키도 필요 없습니다. 위 섹션이나 [ffraud.com/tools/email-blacklist-check](https://ffraud.com/tools/email-blacklist-check)의 무료 검사 도구를 보세요.

</details>

## 함께 만들기

이 데이터베이스는 쓰는 사람들과 함께 자랍니다. 서버나 fail2ban, WAF, 또는 자체 허니팟을 운영한다면 당신을 때린 것을 보내주세요. 저희가 공개합니다. [ffraud.com/report](https://ffraud.com/report)에서 신고하거나, fail2ban을 [바로 쓸 수 있는 엔드포인트](https://ffraud.com/docs/contribute)로 향하게 하거나, 여기에 이슈를 열면 됩니다. 모든 제보를 검증하고 중복을 걸러 점수를 매기며, 확인된 것은 다음 빌드, 즉 30분 안에 반영됩니다. 원하시면 크레딧도 남깁니다.
