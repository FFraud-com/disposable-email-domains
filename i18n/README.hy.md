# Մեկանգամյա էլփոստի տիրույթներ, վերակառուցվում են ամեն 30 րոպեն մեկ

<p align="center"><b>219,506 մեկանգամյա և ժամանակավոր էլփոստի տիրույթ։ Մեկ պարզ ցանկ, թարմացվում է շուրջօրյա։</b></p>
<p align="center"><sub>MIT արտոնագիր &middot; առանց գրանցման, առանց API բանալու, առանց հարցումների սահմանի &middot; թարմացվել է 08.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/hy.svg?v=1788885061" alt="Ստուգեք հասցեն անվճար ffraud.com-ում" width="540"></a></p>

Դեն նետվող մուտքի արկղերը հենց այն ճանապարհն են, որով կեղծ հաշիվները զանգվածաբար պատրաստվում են՝ գրանցվիր, վերցրու հաստատման հղումը, այրիր անվճար սահմանը, նորից սկսիր։ Սա [ffraud.com](https://ffraud.com)-ի հետևում կանգնած բաց մեկանգամյա էլփոստի շտեմարանն է՝ ամեն ժամանակավոր և դեն նետվող փոստային տիրույթ, որ կարողանում ենք գտնել, մեկ տեքստային ֆայլում։ Նոր ծառայություններ ամեն օր են ծլում, ուստի ցանկը **ամեն 30 րոպեն մեկ** վերակառուցվում է. այն, ինչ քաշում եք, հենց հիմա կենդանի է, և ոչ թե անցյալ շաբաթվա նկար։ Առանց գրանցման, առանց բանալու, առանց սահմանների։

## Համառոտ

- **219,506** մեկանգամյա և ժամանակավոր էլփոստի տիրույթ, տողում մեկական, դասավորված, պատրաստ ուղղակի `Set`-ի մեջ բեռնելու
- **Ամեն 30 րոպեն մեկ** վերակառուցվում և հրապարակվում է։ Commit-ների պատմությունը փոփոխությունների գրանցամատյանն է, իսկ [`metadata.json`](metadata.json)-ը կրում է կառուցման ճշգրիտ ժամանակը
- Հայտնաբերումը ցանկով չի ավարտվում. [ffraud.com](https://ffraud.com)-ի հետևում գտնվող շարժիչը մեկանգամյա ծառայությունները ճանաչում է նաև իրենց **փոստային ենթակառուցվածքով**, և այդպես բոլորովին նոր տիրույթը բռնում է հայտնվելու օրը, նախքան որևէ ցանկում հայտնվելը
- Լայն տարածում ունեցող և վճարովի փոստային մատակարարները միտումնավոր **բացառված են**, որպեսզի սեփական տիրույթի վրա գտնվող իրական հաճախորդը երբեք մեկանգամյա ծառայության հետ չշփոթվի
- **MIT արտոնագիր**, ներառյալ առևտրային օգտագործումը, հեղինակի նշում չի պահանջվում
- Մեկ միակ տեքստային ֆայլ։ Ոչ արխիվ, ոչ սխեմա, ոչ հաճախորդի գրադարան

## Արագ մեկնարկ

```bash
# Ամբողջ ցանկը, տողում մեկ տիրույթ
curl -s https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/disposable-email-domains.txt
```

Բեռնեք այն `Set`-ի մեջ և մերժեք հասցեի տիրույթային մասը հենց գրանցման ժամանակ։ Այս չափի դեպքում հիշողության մեջ որոնումը ոչինչ չարժե, և մեկանգամյա հաշիվն արգելափակում եք, նախքան այն ձեր շտեմարանին հասնելը։

## Ստուգեք մեկ հասցե՝ առանց որևէ բան ներբեռնելու

Մեկ հասցե ստուգելու համար ցանկը ներբեռնելու կարիք չկա։ Հանրային API-ն բանալի չի պահանջում և օրական սահման էլ չունի.

```bash
# Ամբողջական տեղեկություն մեկ IP-ի մասին՝ միավոր, պատճառ, կարգեր
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Այս հասցեն մեկանգամյա՞ է
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Այս տիրույթը բաժանո՞ւմ է դեն նետվող փոստարկղեր
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Գործակալների և օգնականների համար՝ [ffraud.com/llms.txt](https://ffraud.com/llms.txt)-ը մեքենաների ցուցիչն է, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt)-ը պահում է ողջ փաստաթղթերը մաքուր Markdown-ով, իսկ [ffraud.com/openapi.json](https://ffraud.com/openapi.json)-ը OpenAPI բնութագիրն է։ Երեքն էլ հանրային են, բանալի չեն պահանջում և ստեղծված են ուղղակի վերցնելու համար։ Ովքեր էջն են նախընտրում, անվճար ստուգիչները [ffraud.com/tools](https://ffraud.com/tools) հասցեում են։

## Ինչպես է կառուցվում ցանկը

Երկու բան է այն կառուցում՝ մեր սեփական մեղրաթակարդների սենսորային ցանցը, որը հետևում է, թե որ ծառայություններն են բաժանում դեն նետվող փոստարկղեր, և այն մարդկանց հաղորդումները, ում գրանցման ձևը չարաշահվել է։ Յուրաքանչյուր թեկնածու ffraud շարժիչի կողմից ստուգվում է հրապարակումից առաջ։

Շարժիչը մեկանգամյա ծառայությունը ճանաչում է ոչ միայն տիրույթի անունով, այլև **դրա հետևում գտնվող փոստային ենթակառուցվածքով**։ Այդպիսի ծառայություններ վարողներն անդադար նոր տիրույթներ են գնում, բայց շարունակում են դրանք ուղղել նույն մի բուռ փոստային սերվերներին, ուստի բոլորովին նոր տիրույթը կարելի է ճանաչել հայտնվելու օրը, շաբաթներ առաջ, քան այն որևէ ցանկ ընկնի։

Հենց նույն դատողությունն է իրական ընկերություններին այս ցանկից դուրս պահում։ Լայն հանրությանը սպասարկող փոստային հարթակները՝ Google Workspace-ից և Microsoft 365-ից մինչև IONOS, Strato, GMX, Proton, Zoho և iCloud, բացառված են անվանապես, քանի որ այն, որ մեկանգամյա ծառայությունը տիրույթ է կայանել մեկ միլիոն իրական հաճախորդի կողքին, այդ հաճախորդների մասին ոչինչ չի ասում։ Այստեղ զգուշությունը մեզ մի քանի հայտնաբերում է արժենում. անփութությունը որևէ մեկին կարժենար մեկ իրական գրանցում։

Ոչ։ Լայն տարածում ունեցող փոստային մատակարարները՝ և՛ անհատական, և՛ բիզնես, միտումնավոր բացառված են, ինչպես նաև այն հարթակները, որոնք ուրիշների տիրույթների փոստն են վարում։ Ցանկում միայն մեկանգամյա ծառայություններ են։

</details>

<details>
<summary><b>Մի տիրույթ պակասում է։ Կարո՞ղ եմ ավելացնել</b></summary>

Խնդրում ենք, ավելացրեք։ Հայտնեք [ffraud.com/report](https://ffraud.com/report)-ում կամ բացեք issue այստեղ։ Մենք ստուգում ենք, և հաստատված տիրույթները դուրս են գալիս հաջորդ կառուցման ժամանակ, կես ժամվա ընթացքում։

</details>

<details>
<summary><b>Ցանկում ինչ-որ օրինական բան է հայտնվել։ Ինչպե՞ս հեռացնեմ</b></summary>

Ասեք մեզ [ffraud.com/report](https://ffraud.com/report)-ում՝ նշելով տիրույթը։ Կեղծ հայտնաբերումը սխալի թանկ տեսակն է, և մենք էլ այդպես ենք վերաբերվում դրան. հաստատվածը մաքրվում է հաջորդ կառուցման ժամանակ։

</details>

<details>
<summary><b>Կա՞ API առանձին հասցեների համար</b></summary>

Կա, և դրան բանալի պետք չէ։ Տեսեք վերևի բաժինը կամ անվճար ստուգիչը [ffraud.com/tools/email-blacklist-check](https://ffraud.com/tools/email-blacklist-check)-ում։

</details>

## Օգնեք կառուցել

Այս շտեմարանն աճում է նրանց հետ, ովքեր օգտագործում են այն։ Եթե սերվերներ, fail2ban, WAF կամ ձեր սեփական մեղրաթակարդներն եք վարում, ուղարկեք մեզ այն, ինչը հարձակվում է ձեզ վրա, և մենք կհրապարակենք՝ հայտնեք [ffraud.com/report](https://ffraud.com/report)-ում, ուղղեք fail2ban-ը [պատրաստի ծայրակետին](https://ffraud.com/docs/contribute), կամ բացեք issue այստեղ։ Յուրաքանչյուր ուղարկվածը ստուգում ենք, կրկնությունները հեռացնում և միավոր տալիս. հաստատվածը դուրս է գալիս հաջորդ կառուցման ժամանակ, այսինքն՝ կես ժամվա ընթացքում, ցանկության դեպքում ձեր անունով։
