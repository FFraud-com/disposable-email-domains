# ఒకసారి వాడే ఇమెయిల్ డొమైన్‌లు, ప్రతి 30 నిమిషాలకు పునర్నిర్మాణం

<p align="center"><b>219,617 ఒకసారి వాడే, తాత్కాలిక ఇమెయిల్ డొమైన్‌లు. ఒకే ఒక సాదా జాబితా, రేయింబవళ్లు తాజా చేయబడుతుంది.</b></p>
<p align="center"><sub>MIT లైసెన్స్ &middot; నమోదు లేదు, API కీ లేదు, అభ్యర్థన పరిమితి లేదు &middot; నవీకరించబడింది 12.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/te.svg?v=1789221655" alt="ffraud.com లో ఒక చిరునామాను ఉచితంగా తనిఖీ చేయండి" width="540"></a></p>

పారేసే ఇన్‌బాక్స్‌లే నకిలీ ఖాతాలను పెద్ద ఎత్తున తయారు చేసే దారి: నమోదు చేయి, నిర్ధారణ లింక్ తీసుకో, ఉచిత పరిమితిని కాల్చేయి, మళ్లీ మొదలుపెట్టు. ఇది [ffraud.com](https://ffraud.com) వెనుక నిలిచిన బహిరంగ ఒకసారి వాడే ఇమెయిల్ డేటాబేస్: మేము కనుగొనగలిగిన ప్రతి తాత్కాలిక, పారేసే మెయిల్ డొమైన్, ఒకే టెక్స్ట్ ఫైల్‌లో. కొత్త సేవలు ప్రతిరోజూ పుట్టుకొస్తాయి, కాబట్టి జాబితా **ప్రతి 30 నిమిషాలకు** తిరిగి నిర్మించబడుతుంది: మీరు లాగేది ఇప్పుడు బతికే ఉంది, గత వారపు చిత్రం కాదు. నమోదు లేదు, కీ లేదు, పరిమితి లేదు.

## క్లుప్తంగా

- **219,617** ఒకసారి వాడే, తాత్కాలిక ఇమెయిల్ డొమైన్‌లు, ప్రతి వరుసకు ఒకటి, క్రమబద్ధీకరించబడినవి, నేరుగా ఒక `Set` లోకి ఎక్కించడానికి సిద్ధం
- **ప్రతి 30 నిమిషాలకు** తిరిగి నిర్మించి ప్రచురించబడుతుంది. commit చరిత్రే మార్పుల నమోదు, [`metadata.json`](metadata.json) లో నిర్మాణ ఖచ్చిత సమయం ఉంటుంది
- గుర్తింపు జాబితాతో ఆగదు: [ffraud.com](https://ffraud.com) వెనుక ఇంజిన్ ఒకసారి వాడే సేవలను వాటి **మెయిల్ మౌలిక వసతి** నుంచి కూడా గుర్తిస్తుంది, అలా సరికొత్త డొమైన్‌ను అది కనిపించిన రోజునే పట్టుకుంటుంది, ఏ జాబితాలోనూ చేరకముందే
- ప్రధాన స్రవంతి, చెల్లింపు మెయిల్ సేవలు ఉద్దేశపూర్వకంగా **మినహాయించబడ్డాయి**, తన సొంత డొమైన్‌లో ఉన్న నిజమైన ఖాతాదారుడు ఎప్పుడూ ఒకసారి వాడే సేవగా పొరబడకుండా
- **MIT లైసెన్స్**, వాణిజ్య వినియోగంతో సహా, మూలం పేర్కొనడం అవసరం లేదు
- ఒకే ఒక టెక్స్ట్ ఫైల్. ఆర్కైవ్ లేదు, స్కీమా లేదు, క్లయింట్ లైబ్రరీ లేదు

## త్వరిత ప్రారంభం

```bash
# మొత్తం జాబితా, ప్రతి వరుసకు ఒక డొమైన్
curl -s https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/disposable-email-domains.txt
```

దాన్ని ఒక `Set` లోకి ఎక్కించి, నమోదు సమయంలోనే చిరునామాలోని డొమైన్ భాగాన్ని తిరస్కరించండి. ఈ పరిమాణంలో జ్ఞాపకంలో వెతకడం దాదాపు ఉచితం, ఒకసారి వాడే ఖాతా మీ డేటాబేస్‌కు చేరకముందే అడ్డుకోబడుతుంది.

## ఏమీ డౌన్‌లోడ్ చేయకుండా ఒక చిరునామాను తనిఖీ చేయండి

ఒక చిరునామా తనిఖీ చేయడానికి జాబితాను దించుకోవాల్సిన అవసరం లేదు. బహిరంగ API కీ అడగదు, రోజువారీ పరిమితీ లేదు:

```bash
# ఒక IP గురించి పూర్తి సమాచారం: స్కోరు, కారణం, వర్గాలు
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ఈ చిరునామా ఒకసారి వాడేదా?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# ఈ డొమైన్ పారేసే మెయిల్‌బాక్స్‌లను పంచుతోందా?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

ఏజెంట్లు, సహాయకుల కోసం: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) యంత్రాల కోసం సూచిక, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) మొత్తం డాక్యుమెంటేషన్‌ను సాదా Markdown రూపంలో ఉంచుతుంది, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) OpenAPI వివరణ. మూడూ బహిరంగమే, కీ అడగవు, నేరుగా తీసుకోవడానికే తయారు చేయబడ్డాయి. పేజీ ఇష్టపడేవారికి ఉచిత తనిఖీ సాధనాలు [ffraud.com/tools](https://ffraud.com/tools) లో ఉన్నాయి.

## ఈ జాబితా ఎలా నిర్మించబడుతుంది

రెండు విషయాలు దీన్ని నిర్మిస్తాయి: ఏ సేవలు పారేసే మెయిల్‌బాక్స్‌లను పంచుతున్నాయో గమనించే మా సొంత హనీపాట్ సెన్సార్ నెట్‌వర్క్, మరియు నమోదు ఫారం దుర్వినియోగానికి గురైనవారి నివేదికలు. ప్రచురణకు ముందు ప్రతి అభ్యర్థి డొమైన్‌ను ffraud ఇంజిన్ ధృవీకరిస్తుంది.

ఇంజిన్ ఒకసారి వాడే సేవను డొమైన్ పేరుతో మాత్రమే కాక **దాని వెనుక ఉన్న మెయిల్ మౌలిక వసతితో** కూడా గుర్తిస్తుంది. అలాంటి సేవలు నడిపేవారు నిరంతరం కొత్త డొమైన్‌లు కొంటారు కానీ వాటిని అవే కొద్దిపాటి మెయిల్ సర్వర్ల వైపే మళ్లిస్తారు, కాబట్టి సరికొత్త డొమైన్‌ను అది కనిపించిన రోజునే గుర్తించవచ్చు, ఏ జాబితాకైనా చేరడానికి వారాల ముందే.

అదే తర్కమే నిజమైన సంస్థలను ఈ జాబితా బయట ఉంచుతుంది. సామాన్య ప్రజలకు సేవలందించే మెయిల్ వేదికలు, Google Workspace, Microsoft 365 నుంచి IONOS, Strato, GMX, Proton, Zoho, iCloud వరకు, పేరు పెట్టి మినహాయించబడ్డాయి, ఎందుకంటే ఒక ఒకసారి వాడే సేవ పది లక్షల నిజమైన ఖాతాదారుల పక్కన ఒక డొమైన్ నిలిపితే అది ఆ ఖాతాదారుల గురించి ఏమీ చెప్పదు. ఇక్కడ జాగ్రత్త మాకు కొన్ని గుర్తింపులను కోల్పోయేలా చేస్తుంది; అజాగ్రత్త ఎవరికో ఒక నిజమైన నమోదును కోల్పోయేలా చేస్తుంది.
