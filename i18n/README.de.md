# Wegwerf-E-Mail-Domains, alle 30 Minuten neu gebaut

<p align="center"><b>219.506 Wegwerf-, Einweg- und Temporär-E-Mail-Domains. Eine schlichte Liste, rund um die Uhr aufgefrischt.</b></p>
<p align="center"><sub>MIT-Lizenz &middot; keine Anmeldung, kein API-Schlüssel, kein Limit &middot; aktualisiert am 08.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/de.svg?v=1788881535" alt="Eine Adresse kostenlos auf ffraud.com prüfen" width="540"></a></p>

Wegwerf-Postfächer sind der Weg, auf dem gefälschte Konten in Masse entstehen: anmelden, Bestätigungslink abgreifen, Gratiskontingent verbrennen, von vorn. Das ist die offene Wegwerf-E-Mail-Datenbank hinter [ffraud.com](https://ffraud.com), jede temporäre und Wegwerf-Maildomain, die wir finden können, in einer schlichten Textdatei. Neue Wegwerfdienste entstehen jeden Tag, deshalb wird die Liste **alle 30 Minuten** neu gebaut: Was Sie ziehen, ist gerade jetzt aktiv, keine Momentaufnahme von letzter Woche. Keine Anmeldung, kein API-Schlüssel, kein Limit.

## Die wichtigsten Zahlen

- **219.506** Wegwerf- und Temporär-E-Mail-Domains, eine pro Zeile, sortiert, fertig für ein `Set`
- Wird **alle 30 Minuten** neu gebaut und hochgeladen. Die Commit-Historie ist das Änderungsprotokoll, und [`metadata.json`](metadata.json) trägt die genaue Bauzeit
- Die Erkennung geht über die Liste hinaus: Die Engine hinter [ffraud.com](https://ffraud.com) erkennt Wegwerfdienste auch an ihrer **Mail-Infrastruktur**, und fängt damit eine brandneue Domain am Tag ihres Auftauchens ab, bevor sie auf irgendeiner Liste steht
- Verbreitete und kostenpflichtige Mailanbieter sind bewusst **ausgeschlossen**, damit ein echter Kunde mit eigener Domain nie für einen Wegwerfdienst gehalten wird
- **MIT-Lizenz**, kommerzielle Nutzung eingeschlossen, keine Namensnennung nötig
- Eine schlichte Textdatei. Kein Archiv, kein Schema, keine Bibliothek

## Schnellstart

```bash
# Die ganze Liste, eine Domain pro Zeile
curl -s https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/disposable-email-domains.txt
```

In ein `Set` laden und den Domain-Teil einer Adresse bei der Anmeldung ablehnen. In dieser Größenordnung kostet ein Lookup im Arbeitsspeicher nichts, und Sie blockieren das Wegwerfkonto, bevor es überhaupt in Ihre Datenbank gelangt.

## Eine einzelne Adresse prüfen, ohne etwas herunterzuladen

Sie müssen die Liste nicht herunterladen, um eine einzelne Adresse zu prüfen. Die öffentliche API braucht keinen Schlüssel und hat kein Tageslimit:

```bash
# Vollständige Auskunft zu einer IP: Score, Begründung, Kategorien
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Ist diese Adresse eine Wegwerfadresse?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Vergibt diese Domain Wegwerf-Postfächer?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Für Agenten und Assistenten: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) ist der Maschinen-Index, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) enthält jede Doku-Seite als reines Markdown, und [ffraud.com/openapi.json](https://ffraud.com/openapi.json) ist die OpenAPI-Spezifikation. Alle drei sind öffentlich, brauchen keinen Schlüssel und sind zum direkten Abruf gedacht. Wer lieber eine Seite benutzt, findet die kostenlosen Prüfwerkzeuge unter [ffraud.com/tools](https://ffraud.com/tools).

## Wie die Liste entsteht

Zwei Dinge bauen sie: unser eigenes Honeypot-Sensornetz, das beobachtet, welche Dienste Wegwerf-Postfächer ausgeben, und Meldungen von Leuten, deren Anmeldeformulare missbraucht wurden. Jeder Kandidat wird von der ffraud-Engine geprüft, bevor er veröffentlicht wird.

Die Engine erkennt einen Wegwerfdienst außerdem an der **Mail-Infrastruktur dahinter**, nicht nur am Domainnamen. Betreiber solcher Dienste kaufen ständig neue Domains, richten sie aber immer wieder auf dieselbe Handvoll Mailserver, sodass eine brandneue Domain am Tag ihres Auftauchens erkannt werden kann, Wochen bevor sie auf einer Liste steht.

Dieselbe Überlegung hält echte Unternehmen von dieser Liste fern. Mailplattformen für die Allgemeinheit, von Google Workspace und Microsoft 365 bis IONOS, Strato, GMX, Proton, Zoho und iCloud, sind namentlich ausgeschlossen, denn ein Wegwerfdienst, der eine Domain neben einer Million echter Kunden parkt, sagt über diese Kunden nichts aus. Vorsicht an dieser Stelle kostet uns ein paar Treffer; Nachlässigkeit würde jemanden eine echte Anmeldung kosten.

<details>
<summary><b>Darf ich das in einem kommerziellen Produkt einsetzen?</b></summary>

Ja. MIT, keine Namensnennung nötig, keine getrennte kommerzielle Lizenz, niemand zu fragen.

</details>

<details>
<summary><b>Blockiert das Gmail, Proton oder die eigenen Domains meiner Kunden?</b></summary>

Nein. Verbreitete Anbieter für Privat- und Geschäftskunden sind bewusst ausgeschlossen, ebenso die Plattformen, die Mail für fremde Domains betreiben. Die Liste enthält ausschließlich Wegwerfdienste.

</details>

<details>
<summary><b>Eine Domain fehlt. Kann ich sie ergänzen?</b></summary>

Sehr gern. Melden Sie sie unter [ffraud.com/report](https://ffraud.com/report) oder öffnen Sie hier ein Issue. Wir prüfen sie, und bestätigte Domains gehen im nächsten Build mit, innerhalb einer halben Stunde.

</details>

<details>
<summary><b>Etwas Seriöses steht auf der Liste. Wie bekomme ich es entfernt?</b></summary>

Sagen Sie uns unter [ffraud.com/report](https://ffraud.com/report) die Domain. Fehlalarme sind die teure Sorte Fehler, und wir behandeln sie auch so: Ein bestätigter wird im nächsten Build bereinigt.

</details>

<details>
<summary><b>Gibt es eine API für einzelne Adressen?</b></summary>

Ja, und sie braucht keinen Schlüssel. Siehe den Abschnitt oben oder das kostenlose Prüfwerkzeug unter [ffraud.com/tools/email-blacklist-check](https://ffraud.com/tools/email-blacklist-check).

</details>

## Mitbauen

Diese Datenbank wächst mit den Leuten, die sie benutzen. Wer Server, fail2ban, eine WAF oder eigene Honeypots betreibt, schickt uns, was ihn angreift, und wir veröffentlichen es: melden unter [ffraud.com/report](https://ffraud.com/report), fail2ban auf den [fertigen Endpunkt](https://ffraud.com/docs/contribute) zeigen lassen oder hier ein Issue öffnen. Wir prüfen, entdoppeln und bewerten jede Einsendung; bestätigte gehen im nächsten Build mit, also innerhalb einer halben Stunde, auf Wunsch mit Namensnennung.
