# एकदाच वापरायचे ईमेल डोमेन, दर 30 मिनिटांनी पुन्हा बांधले जातात

<p align="center"><b>219,610 एकदाच वापरायचे आणि तात्पुरते ईमेल डोमेन. एकच साधी यादी, रात्रंदिवस ताजी केली जाते.</b></p>
<p align="center"><sub>MIT परवाना &middot; नोंदणी नाही, API किल्ली नाही, विनंत्यांची मर्यादा नाही &middot; अद्ययावत 12.09.2026</sub></p>

फेकून द्यायच्या इनबॉक्समधूनच बनावट खाती मोठ्या प्रमाणावर तयार होतात: नोंदणी कर, पडताळणीची दुवा उचल, मोफत मर्यादा जाळ, पुन्हा सुरू कर. हा [ffraud.com](https://ffraud.com) मागे उभा असलेला खुला एकदाच वापरायच्या ईमेलचा डेटाबेस आहे: आम्हाला सापडलेला प्रत्येक तात्पुरता आणि फेकून द्यायचा टपाल डोमेन, एकाच मजकूर फाइलमध्ये. नव्या सेवा रोज उगवतात, म्हणून यादी **दर 30 मिनिटांनी** पुन्हा बांधली जाते: तुम्ही जे ओढता ते आत्ता जिवंत आहे, गेल्या आठवड्याचे छायाचित्र नाही. नोंदणी नाही, किल्ली नाही, मर्यादा नाही.

## थोडक्यात

- **219,610** एकदाच वापरायचे आणि तात्पुरते ईमेल डोमेन, प्रत्येक ओळीवर एक, क्रमवार, थेट `Set` मध्ये भरण्यास तयार
- **दर 30 मिनिटांनी** पुन्हा बांधून प्रसिद्ध होते. commit चा इतिहासच बदलांची नोंद आहे, आणि [`metadata.json`](metadata.json) मध्ये बांधणीची नेमकी वेळ असते
- ओळख यादीपाशी थांबत नाही: [ffraud.com](https://ffraud.com) मागचे इंजिन एकदाच वापरायच्या सेवा त्यांच्या **टपाल पायाभूत सुविधेवरूनही** ओळखते, त्यामुळे अगदी नवा डोमेन तो उगवलेल्या दिवशीच पकडते, कोणत्याही यादीत येण्याआधी
- मुख्य प्रवाहातले आणि सशुल्क टपाल पुरवठादार मुद्दाम **वगळलेले आहेत**, म्हणजे स्वतःच्या डोमेनवरचा खरा ग्राहक कधीही एकदाच वापरायची सेवा समजला जाणार नाही
- **MIT परवाना**, व्यावसायिक वापरासह, श्रेय देणे आवश्यक नाही
- एकच मजकूर फाइल. संग्रह नाही, रचना नाही, क्लायंट ग्रंथालय नाही

## झटपट सुरुवात

```bash
# संपूर्ण यादी, प्रत्येक ओळीवर एक डोमेन
curl -s https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/disposable-email-domains.txt
```

ती एका `Set` मध्ये भरा आणि नोंदणीच्या वेळीच पत्त्याचा डोमेन भाग नाकारा. या आकारात स्मृतीत शोधणे जवळपास फुकट आहे, आणि एकदाच वापरायचे खाते तुमच्या डेटाबेसपर्यंत पोहोचण्याआधीच अडवले जाते.

## काहीही न उतरवता एक पत्ता तपासा

एक पत्ता तपासण्यासाठी यादी उतरवण्याची गरज नाही. सार्वजनिक API किल्ली मागत नाही आणि त्याला रोजची मर्यादाही नाही:

```bash
# एका IP ची संपूर्ण माहिती: गुण, कारण, वर्ग
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# हा पत्ता एकदाच वापरायचा आहे का?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# हे डोमेन फेकून द्यायच्या टपालपेट्या वाटते का?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

एजंट आणि सहाय्यकांसाठी: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) ही यंत्रांसाठीची अनुक्रमणिका आहे, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) मध्ये संपूर्ण दस्तऐवज साध्या Markdown रूपात आहे, आणि [ffraud.com/openapi.json](https://ffraud.com/openapi.json) हे OpenAPI तपशील आहे. तिन्ही सार्वजनिक आहेत, किल्ली मागत नाहीत, आणि थेट घेण्यासाठीच बनवली आहेत. ज्यांना पान आवडते त्यांच्यासाठी मोफत तपासणी साधने [ffraud.com/tools](https://ffraud.com/tools) वर आहेत.

## ही यादी कशी उभी राहते

दोन गोष्टी ती उभारतात: कोणत्या सेवा फेकून द्यायच्या टपालपेट्या वाटत आहेत हे पाहणारे आमचे स्वतःचे मधाच्या सापळ्यांचे संवेदक जाळे, आणि ज्यांच्या नोंदणी अर्जाचा गैरवापर झाला त्यांचे अहवाल. प्रसिद्ध करण्याआधी प्रत्येक संभाव्य डोमेन ffraud इंजिन तपासते.

इंजिन एकदाच वापरायची सेवा फक्त डोमेनच्या नावावरून नव्हे तर **तिच्यामागच्या टपाल पायाभूत सुविधेवरूनही** ओळखते. अशा सेवा चालवणारे सतत नवे डोमेन विकत घेतात पण त्यांना त्याच मूठभर टपाल सर्व्हरकडेच वळवत राहतात, त्यामुळे अगदी नवा डोमेनही तो उगवलेल्या दिवशीच ओळखता येतो, कोणत्याही यादीत पोहोचण्याच्या आठवडे आधी.

हाच युक्तिवाद खऱ्या कंपन्यांना या यादीबाहेर ठेवतो. सर्वसामान्य जनतेला सेवा देणारे टपाल मंच, Google Workspace आणि Microsoft 365 पासून IONOS, Strato, GMX, Proton, Zoho आणि iCloud पर्यंत, नाव घेऊन वगळलेले आहेत, कारण एखादी एकदाच वापरायची सेवा दहा लाख खऱ्या ग्राहकांशेजारी डोमेन उभा करते म्हणून त्या ग्राहकांबद्दल काहीच सिद्ध होत नाही. इथली सावधगिरी आम्हाला काही ओळखी गमवायला लावते; निष्काळजीपणा कुणाची तरी एक खरी नोंदणी गमवायला लावेल.
