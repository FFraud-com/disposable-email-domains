<p align="center"><b>219,617 ஒருமுறை பயன்பாட்டு மற்றும் தற்காலிக மின்னஞ்சல் டொமைன்கள். ஒரே எளிய பட்டியல், இரவும் பகலும் புதுப்பிக்கப்படுகிறது.</b></p>

தூக்கி எறியும் இன்பாக்ஸ்கள்தான் போலி கணக்குகள் மொத்தமாகத் தயாரிக்கப்படும் வழி: பதிவு செய், உறுதிப்படுத்தல் இணைப்பை எடு, இலவச வரம்பை எரி, மீண்டும் தொடங்கு. இது [ffraud.com](https://ffraud.com) பின்னால் நிற்கும் திறந்த ஒருமுறை பயன்பாட்டு மின்னஞ்சல் தரவுத்தளம்: நாங்கள் கண்டுபிடிக்கக்கூடிய ஒவ்வொரு தற்காலிக மற்றும் தூக்கி எறியும் அஞ்சல் டொமைனும், ஒரே உரைக் கோப்பில். புதிய சேவைகள் தினமும் தோன்றுகின்றன, எனவே பட்டியல் **ஒவ்வொரு 30 நிமிடமும்** மீளக் கட்டப்படுகிறது: நீங்கள் இழுப்பது இப்போது உயிருடன் இருக்கிறது, கடந்த வாரத்துப் படம் அல்ல. பதிவு இல்லை, சாவி இல்லை, வரம்பு இல்லை.

## எதையும் பதிவிறக்காமல் ஒரு முகவரியைச் சரிபார்க்கவும்

ஒரு முகவரியைச் சரிபார்க்கப் பட்டியலைப் பதிவிறக்க வேண்டியதில்லை. பொது API சாவி கேட்பதில்லை, நாள் வரம்பும் இல்லை:

```bash
# ஒரு IP பற்றிய முழுத் தகவல்: மதிப்பெண், காரணம், வகைகள்
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# இந்த முகவரி ஒருமுறை பயன்பாட்டுடையதா?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# இந்த டொமைன் தூக்கி எறியும் அஞ்சல் பெட்டிகளை வழங்குகிறதா?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

முகவர்களுக்கும் உதவியாளர்களுக்கும்: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) இயந்திரங்களுக்கான அட்டவணை, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) முழு ஆவணங்களையும் எளிய Markdown ஆக வைத்திருக்கிறது, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) என்பது OpenAPI விவரக்குறிப்பு. மூன்றுமே பொதுவானவை, சாவி கேட்பதில்லை, நேரடியாக எடுத்துக்கொள்ளவே உருவாக்கப்பட்டவை. பக்கம் விரும்புபவர்களுக்கு இலவச சரிபார்ப்புக் கருவிகள் [ffraud.com/tools](https://ffraud.com/tools) இல் உள்ளன.

## இந்தப் பட்டியல் எப்படிக் கட்டப்படுகிறது

இரண்டு விஷயங்கள் இதைக் கட்டுகின்றன: எந்தச் சேவைகள் தூக்கி எறியும் அஞ்சல் பெட்டிகளை வழங்குகின்றன என்பதைக் கவனிக்கும் எங்கள் சொந்த ஹனிபாட் உணரி வலையமைப்பு, மற்றும் பதிவுப் படிவம் தவறாகப் பயன்படுத்தப்பட்டவர்களின் அறிக்கைகள். வெளியிடுவதற்கு முன் ஒவ்வொரு வேட்பாளர் டொமைனையும் ffraud இயந்திரம் சரிபார்க்கிறது.

இயந்திரம் ஒருமுறை பயன்பாட்டுச் சேவையை டொமைன் பெயரால் மட்டுமல்ல, **அதன் பின்னாலுள்ள அஞ்சல் உள்கட்டமைப்பாலும்** அடையாளம் காண்கிறது. இத்தகைய சேவைகளை இயக்குபவர்கள் இடைவிடாமல் புதிய டொமைன்களை வாங்குகிறார்கள், ஆனால் அவற்றை அதே சில அஞ்சல் சேவையகங்களுக்கே திருப்பிக்கொண்டிருக்கிறார்கள், எனவே புத்தம் புதிய டொமைனையும் அது தோன்றிய அன்றே அடையாளம் காண முடியும், அது எந்தப் பட்டியலுக்கும் வருவதற்கு வாரங்களுக்கு முன்பே.

இதே தர்க்கமே உண்மையான நிறுவனங்களை இந்தப் பட்டியலுக்கு வெளியே வைத்திருக்கிறது. பொது மக்களுக்குச் சேவை செய்யும் அஞ்சல் தளங்கள், Google Workspace மற்றும் Microsoft 365 முதல் IONOS, Strato, GMX, Proton, Zoho மற்றும் iCloud வரை, பெயர் சொல்லி விலக்கப்பட்டுள்ளன, ஏனெனில் ஒரு ஒருமுறை பயன்பாட்டுச் சேவை பத்து லட்சம் உண்மையான வாடிக்கையாளர்களுக்குப் பக்கத்தில் ஒரு டொமைனை நிறுத்தினால் அது அந்த வாடிக்கையாளர்களைப் பற்றி எதையும் சொல்லாது. இங்கே கவனமாக இருப்பது எங்களுக்குச் சில கண்டறிதல்களை இழக்கச் செய்கிறது; கவனக்குறைவு யாருக்காவது ஒரு உண்மையான பதிவை இழக்கச் செய்யும்.

## கேள்விகள்

<details>
<summary><b>உண்மையில் எத்தனை முறை புதுப்பிக்கப்படுகிறது?</b></summary>

ஒவ்வொரு 30 நிமிடமும்: இயங்கும் இயந்திரத்திலிருந்து மீளக் கட்டப்பட்டு இங்கே அனுப்பப்படுகிறது. இந்தக் களஞ்சியத்தின் commit பட்டியலே நேர்மையான பதிவு, மேலும் [`metadata.json`](metadata.json) உங்கள் நகலின் துல்லியமான UTC கட்டமைப்பு நேரத்தைச் சுமக்கிறது.

</details>

<details>
<summary><b>இதை வணிகப் பொருளில் பயன்படுத்தலாமா?</b></summary>

ஆம். MIT: பெயர் குறிப்பிடல் கட்டாயமில்லை, தனி வணிக உரிமம் இல்லை, யாரிடமும் கேட்க வேண்டியதில்லை.

</details>

<details>
<summary><b>இது Gmail, Proton அல்லது என் வாடிக்கையாளர்களின் சொந்த டொமைன்களைத் தடுக்குமா?</b></summary>

இல்லை. தனிநபர் மற்றும் வணிகம் ஆகிய இரு வகைப் பரவலான அஞ்சல் வழங்குநர்களும் வேண்டுமென்றே விலக்கப்பட்டுள்ளனர், பிறர் டொமைன்களுக்கு அஞ்சல் இயக்கும் தளங்களும் அப்படியே. பட்டியலில் ஒருமுறை பயன்பாட்டுச் சேவைகள் மட்டுமே.

</details>

<details>
<summary><b>ஒரு டொமைன் விடுபட்டுள்ளது. சேர்க்கலாமா?</b></summary>

டொமைனுடன் [ffraud.com/report](https://ffraud.com/report) இல் எங்களிடம் சொல்லுங்கள். தவறான கண்டறிதல் விலையுயர்ந்த வகைத் தவறு, நாங்களும் அப்படியே நடத்துகிறோம்: உறுதிப்படுத்தப்பட்டால் அடுத்த கட்டமைப்பில் நீக்கப்படும்.

## கட்ட உதவுங்கள்

இந்தத் தரவுத்தளம் அதைப் பயன்படுத்துபவர்களுடன் சேர்ந்தே வளர்கிறது. நீங்கள் சேவையகங்கள், fail2ban, WAF அல்லது சொந்த ஹனிபாட்கள் இயக்கினால், உங்களைத் தாக்குவதை எங்களுக்கு அனுப்புங்கள், நாங்கள் வெளியிடுகிறோம்: [ffraud.com/report](https://ffraud.com/report) இல் தெரிவியுங்கள், fail2ban ஐ [தயார் நிலை முனைப்புள்ளிக்கு](https://ffraud.com/docs/contribute) திருப்புங்கள், அல்லது இங்கேயே ஒரு issue திறங்கள். ஒவ்வொரு சமர்ப்பிப்பையும் சரிபார்த்து, நகல்களை நீக்கி, மதிப்பெண் இடுகிறோம்; உறுதிப்படுத்தப்பட்டவை அடுத்த கட்டமைப்பில், அதாவது அரை மணி நேரத்திற்குள், வெளியாகும், விரும்பினால் உங்கள் பெயருடன்.
