# 拋棄式信箱網域，每 30 分鐘重建一次

<p align="center"><b>219,530 個拋棄式、臨時、用完即丟的信箱網域。一份純粹的清單，全天候更新。</b></p>
<p align="center"><sub>MIT 授權 &middot; 免註冊、免金鑰、無流量限制 &middot; 更新於 09.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/zh-TW.svg?v=1788960688" alt="在 ffraud.com 上免費檢測一個信箱" width="540"></a></p>

臨時收件匣正是大量製造假帳號的那條路：註冊、拿到確認連結、燒掉免費額度、再來一遍。這是 [ffraud.com](https://ffraud.com) 背後的開放拋棄式信箱資料庫，我們能找到的每一個臨時、拋棄式、用完即丟的郵件網域，都在一個純文字檔裡。新的臨時信箱服務每天都在冒出來，所以這份清單**每 30 分鐘**重建一次：你拉到的是此刻還活著的，不是上週的快照。免註冊、免金鑰、無流量限制。

## 關鍵數字

- **219,530** 個拋棄式與臨時信箱網域，每行一個，已排序，可直接讀進 `Set`
- **每 30 分鐘**重建並推送一次。提交歷史就是變更紀錄，[`metadata.json`](metadata.json) 記錄了精確的建置時間
- 辨識能力不只這份清單：[ffraud.com](https://ffraud.com) 背後的引擎還會透過**郵件基礎設施**認出臨時信箱服務，因此一個全新網域在出現的當天就能被抓到，比任何清單都早
- 主流與付費郵件服務商被刻意**排除在外**，用自有網域的真實客戶絕不會被誤認成臨時信箱服務
- **MIT 授權**，包含商業用途，無需署名
- 一個純文字檔。沒有壓縮檔、沒有 schema、沒有用戶端函式庫

## 快速開始

```bash
# 完整清單，每行一個網域
```

讀進一個 `Set`，在註冊環節直接擋掉信箱位址的網域部分。在這個量級上，記憶體查找幾乎不花成本，而臨時帳號在進入你的資料庫之前就被擋住了。

## 不用下載也能查單一位址

查一個信箱不必把清單下載下來。公開 API 免金鑰，也沒有每日上限：


## 這份清單是怎麼建起來的

兩樣東西撐起它：我們自己的蜜罐感測網路，它盯著哪些服務在發放臨時信箱；以及那些註冊表單被濫用的人送來的回報。每一個候選網域在公開之前，都會由 ffraud 引擎查證。

引擎還會透過**它背後的郵件基礎設施**來辨識臨時信箱服務，而不只看網域名稱。這類服務的營運者不停買新網域，卻總是把它們指向同一小撮郵件伺服器，因此一個全新網域在出現的當天就能被認出來，比它進入任何清單早好幾週。

同樣的道理，也正是把真實企業擋在這份清單之外的原因。面向大眾的郵件平台，從 Google Workspace、Microsoft 365 到 IONOS、Strato、GMX、Proton、Zoho 與 iCloud，都被逐一按名字排除，因為一個臨時信箱服務把網域停在一百萬真實客戶旁邊，並不能說明那些客戶什麼。在這裡保守會讓我們少抓到幾個；而馬虎會讓某個人丟掉一次真實註冊。

不會。面向個人與企業的主流郵件服務商被刻意排除，替別人網域託管郵件的平台同樣如此。這份清單只收臨時信箱服務。
