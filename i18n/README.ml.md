# ഒറ്റത്തവണ ഇമെയിൽ ഡൊമെയ്‌നുകൾ, ഓരോ 30 മിനിറ്റിലും പുനർനിർമ്മിക്കപ്പെടുന്നു

<p align="center"><b>219,617 ഒറ്റത്തവണ, താൽക്കാലിക ഇമെയിൽ ഡൊമെയ്‌നുകൾ. ഒറ്റ ലളിതമായ പട്ടിക, രാവും പകലും പുതുക്കപ്പെടുന്നു.</b></p>
<p align="center"><sub>MIT ലൈസൻസ് &middot; രജിസ്ട്രേഷനില്ല, API കീ ഇല്ല, അഭ്യർത്ഥനാ പരിധിയില്ല &middot; പുതുക്കിയത് 12.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/ml.svg?v=1789243242" alt="ffraud.com ൽ ഒരു വിലാസം സൗജന്യമായി പരിശോധിക്കൂ" width="540"></a></p>

വലിച്ചെറിയാവുന്ന ഇൻബോക്സുകളാണ് വ്യാജ അക്കൗണ്ടുകൾ കൂട്ടത്തോടെ ഉണ്ടാക്കുന്ന വഴി: രജിസ്റ്റർ ചെയ്യുക, സ്ഥിരീകരണ ലിങ്ക് എടുക്കുക, സൗജന്യ പരിധി കത്തിക്കുക, വീണ്ടും തുടങ്ങുക. ഇത് [ffraud.com](https://ffraud.com) ന് പിന്നിൽ നിൽക്കുന്ന തുറന്ന ഒറ്റത്തവണ ഇമെയിൽ ഡാറ്റാബേസാണ്: ഞങ്ങൾക്ക് കണ്ടെത്താനാകുന്ന എല്ലാ താൽക്കാലിക, വലിച്ചെറിയാവുന്ന മെയിൽ ഡൊമെയ്‌നും, ഒറ്റ ടെക്സ്റ്റ് ഫയലിൽ. പുതിയ സേവനങ്ങൾ ദിവസവും ഉയരുന്നു, അതിനാൽ പട്ടിക **ഓരോ 30 മിനിറ്റിലും** പുനർനിർമ്മിക്കപ്പെടുന്നു: നിങ്ങൾ വലിക്കുന്നത് ഇപ്പോൾ ജീവനുള്ളതാണ്, കഴിഞ്ഞ ആഴ്ചയിലെ ചിത്രമല്ല. രജിസ്ട്രേഷനില്ല, കീ ഇല്ല, പരിധിയില്ല.

## ചുരുക്കത്തിൽ

- **219,617** ഒറ്റത്തവണ, താൽക്കാലിക ഇമെയിൽ ഡൊമെയ്‌നുകൾ, ഓരോ വരിയിലും ഒന്ന്, ക്രമീകരിച്ചത്, നേരിട്ട് ഒരു `Set` ലേക്ക് കയറ്റാൻ തയ്യാർ
- **ഓരോ 30 മിനിറ്റിലും** പുനർനിർമ്മിച്ച് പ്രസിദ്ധീകരിക്കുന്നു. commit ചരിത്രമാണ് മാറ്റങ്ങളുടെ രേഖ, [`metadata.json`](metadata.json) ൽ നിർമ്മാണത്തിന്റെ കൃത്യ സമയമുണ്ട്
- കണ്ടെത്തൽ പട്ടികയിൽ അവസാനിക്കുന്നില്ല: [ffraud.com](https://ffraud.com) ന് പിന്നിലെ എൻജിൻ ഒറ്റത്തവണ സേവനങ്ങളെ അവരുടെ **മെയിൽ അടിസ്ഥാനസൗകര്യത്തിൽ** നിന്നും തിരിച്ചറിയുന്നു, അങ്ങനെ തീർത്തും പുതിയ ഒരു ഡൊമെയ്ൻ അത് പ്രത്യക്ഷപ്പെട്ട ദിവസംതന്നെ പിടിക്കുന്നു, ഏതെങ്കിലും പട്ടികയിൽ വരുന്നതിനു മുൻപ്
- മുഖ്യധാരയിലെയും പണം വാങ്ങുന്നതുമായ മെയിൽ ദാതാക്കളെ മനഃപൂർവ്വം **ഒഴിവാക്കിയിരിക്കുന്നു**, സ്വന്തം ഡൊമെയ്‌നിലുള്ള യഥാർത്ഥ ഉപഭോക്താവിനെ ഒരിക്കലും ഒറ്റത്തവണ സേവനമായി തെറ്റിദ്ധരിക്കാതിരിക്കാൻ
- **MIT ലൈസൻസ്**, വാണിജ്യ ഉപയോഗം ഉൾപ്പെടെ, കടപ്പാട് ആവശ്യമില്ല
- ഒറ്റ ടെക്സ്റ്റ് ഫയൽ. ആർക്കൈവില്ല, സ്കീമയില്ല, ക്ലയന്റ് ലൈബ്രറിയില്ല

## ഒന്നും ഡൗൺലോഡ് ചെയ്യാതെ ഒരു വിലാസം പരിശോധിക്കുക

ഒരു വിലാസം പരിശോധിക്കാൻ പട്ടിക ഡൗൺലോഡ് ചെയ്യേണ്ടതില്ല. പൊതു API കീ ചോദിക്കുന്നില്ല, ദിവസേനയുള്ള പരിധിയുമില്ല:

```bash
# ഒരു IP യെക്കുറിച്ചുള്ള പൂർണ്ണ വിവരം: സ്കോർ, കാരണം, വിഭാഗങ്ങൾ
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ഈ വിലാസം ഒറ്റത്തവണ ഉപയോഗത്തിനുള്ളതാണോ?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# ഈ ഡൊമെയ്ൻ വലിച്ചെറിയാവുന്ന മെയിൽബോക്സുകൾ വിതരണം ചെയ്യുന്നുണ്ടോ?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

ഏജന്റുകൾക്കും സഹായികൾക്കും: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) യന്ത്രങ്ങൾക്കുള്ള സൂചികയാണ്, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) മുഴുവൻ രേഖകളും ശുദ്ധമായ Markdown ആയി സൂക്ഷിക്കുന്നു, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) എന്നത് OpenAPI വിവരണമാണ്. മൂന്നും പൊതുവായതാണ്, കീ ചോദിക്കുന്നില്ല, നേരിട്ട് എടുക്കാൻ വേണ്ടിത്തന്നെ ഉണ്ടാക്കിയതാണ്. പേജ് ഇഷ്ടപ്പെടുന്നവർക്ക് സൗജന്യ പരിശോധനാ ഉപകരണങ്ങൾ [ffraud.com/tools](https://ffraud.com/tools) ൽ ഉണ്ട്.

## ഈ പട്ടിക എങ്ങനെ പണിയപ്പെടുന്നു

രണ്ടു കാര്യങ്ങളാണ് ഇത് പണിയുന്നത്: ഏതൊക്കെ സേവനങ്ങൾ വലിച്ചെറിയാവുന്ന മെയിൽബോക്സുകൾ വിതരണം ചെയ്യുന്നുവെന്ന് നിരീക്ഷിക്കുന്ന ഞങ്ങളുടെ സ്വന്തം ഹണിപോട്ട് സെൻസർ ശൃംഖല, പിന്നെ രജിസ്ട്രേഷൻ ഫോം ദുരുപയോഗം ചെയ്യപ്പെട്ടവരുടെ റിപ്പോർട്ടുകൾ. പ്രസിദ്ധീകരിക്കുന്നതിനു മുൻപ് ഓരോ സാധ്യതാ ഡൊമെയ്‌നും ffraud എൻജിൻ പരിശോധിക്കുന്നു.

എൻജിൻ ഒറ്റത്തവണ സേവനത്തെ ഡൊമെയ്ൻ പേരിൽ നിന്ന് മാത്രമല്ല, **അതിനു പിന്നിലെ മെയിൽ അടിസ്ഥാനസൗകര്യത്തിൽ** നിന്നും തിരിച്ചറിയുന്നു. ഇത്തരം സേവനങ്ങൾ നടത്തുന്നവർ ഇടതടവില്ലാതെ പുതിയ ഡൊമെയ്‌നുകൾ വാങ്ങുന്നു, പക്ഷേ അവയെ അതേ ചുരുക്കം മെയിൽ സെർവറുകളിലേക്കുതന്നെ തിരിക്കുന്നു, അതിനാൽ തീർത്തും പുതിയ ഡൊമെയ്ൻ പ്രത്യക്ഷപ്പെട്ട ദിവസംതന്നെ തിരിച്ചറിയാം, ഏതെങ്കിലും പട്ടികയിൽ എത്തുന്നതിന് ആഴ്ചകൾ മുൻപ്.

അതേ യുക്തിയാണ് യഥാർത്ഥ കമ്പനികളെ ഈ പട്ടികയ്ക്ക് പുറത്ത് നിർത്തുന്നത്. പൊതുജനങ്ങൾക്ക് സേവനം നൽകുന്ന മെയിൽ പ്ലാറ്റ്ഫോമുകൾ, Google Workspace, Microsoft 365 മുതൽ IONOS, Strato, GMX, Proton, Zoho, iCloud വരെ, പേരെടുത്ത് ഒഴിവാക്കിയിരിക്കുന്നു, കാരണം ഒരു ഒറ്റത്തവണ സേവനം പത്തുലക്ഷം യഥാർത്ഥ ഉപഭോക്താക്കൾക്കരികിൽ ഒരു ഡൊമെയ്ൻ നിർത്തിയതുകൊണ്ട് ആ ഉപഭോക്താക്കളെക്കുറിച്ച് ഒന്നും തെളിയുന്നില്ല. ഇവിടെ ജാഗ്രത കാണിക്കുന്നത് ഞങ്ങൾക്ക് ചില കണ്ടെത്തലുകൾ നഷ്ടപ്പെടുത്തുന്നു; അശ്രദ്ധ ആർക്കെങ്കിലും ഒരു യഥാർത്ഥ രജിസ്ട്രേഷൻ നഷ്ടപ്പെടുത്തും.

## ചോദ്യങ്ങൾ

<details>
<summary><b>യഥാർത്ഥത്തിൽ എത്ര തവണ പുതുക്കപ്പെടുന്നു?</b></summary>

ഓരോ 30 മിനിറ്റിലും: പ്രവർത്തിക്കുന്ന എൻജിനിൽ നിന്ന് പുനർനിർമ്മിച്ച് ഇവിടേക്ക് അയക്കുന്നു. ഈ ശേഖരത്തിന്റെ commit പട്ടികയാണ് സത്യസന്ധമായ രേഖ, [`metadata.json`](metadata.json) ൽ നിങ്ങളുടെ പകർപ്പിന്റെ കൃത്യമായ UTC നിർമ്മാണ സമയമുണ്ട്.

</details>

<details>
<summary><b>ഇത് വാണിജ്യ ഉൽപ്പന്നത്തിൽ ഉപയോഗിക്കാമോ?</b></summary>

ആകാം. MIT: കടപ്പാട് നിർബന്ധമല്ല, പ്രത്യേക വാണിജ്യ ലൈസൻസില്ല, ആരോടും ചോദിക്കേണ്ടതുമില്ല.

</details>

<details>
<summary><b>ഇത് Gmail, Proton അല്ലെങ്കിൽ എന്റെ ഉപഭോക്താക്കളുടെ സ്വന്തം ഡൊമെയ്‌നുകൾ തടയുമോ?</b></summary>

ഇല്ല. വ്യക്തിപരവും വ്യാപാരപരവുമായ മുഖ്യധാരാ മെയിൽ ദാതാക്കളെ മനഃപൂർവ്വം ഒഴിവാക്കിയിരിക്കുന്നു, മറ്റുള്ളവരുടെ ഡൊമെയ്‌നുകൾക്ക് മെയിൽ നടത്തുന്ന പ്ലാറ്റ്ഫോമുകളെയും. പട്ടികയിൽ ഒറ്റത്തവണ സേവനങ്ങൾ മാത്രമേയുള്ളൂ.

</details>

<details>
<summary><b>ഒരു ഡൊമെയ്ൻ വിട്ടുപോയി. ഞാൻ ചേർക്കട്ടെ?</b></summary>

ദയവായി ചേർക്കൂ. [ffraud.com/report](https://ffraud.com/report) ൽ അറിയിക്കൂ അല്ലെങ്കിൽ ഇവിടെത്തന്നെ ഒരു issue തുറക്കൂ. ഞങ്ങൾ പരിശോധിക്കും, സ്ഥിരീകരിച്ച ഡൊമെയ്‌നുകൾ അടുത്ത ബിൽഡിൽ, അര മണിക്കൂറിനുള്ളിൽ, പുറത്തുവരും.

</details>

<details>
<summary><b>പട്ടികയിൽ നിയമപരമായ എന്തോ കയറിയിട്ടുണ്ട്. എങ്ങനെ നീക്കും?</b></summary>

ഡൊമെയ്ൻ സഹിതം [ffraud.com/report](https://ffraud.com/report) ൽ ഞങ്ങളോട് പറയൂ. തെറ്റായ കണ്ടെത്തൽ ചെലവേറിയ തരം പിഴവാണ്, ഞങ്ങളും അതിനെ അങ്ങനെതന്നെ കാണുന്നു: സ്ഥിരീകരിച്ചാൽ അടുത്ത ബിൽഡിൽ നീക്കം ചെയ്യും.

</details>

ഉണ്ട്, അതിന് കീ വേണ്ട. മുകളിലെ ഭാഗം നോക്കൂ അല്ലെങ്കിൽ [ffraud.com/tools/email-blacklist-check](https://ffraud.com/tools/email-blacklist-check) ലെ സൗജന്യ ഉപകരണം.

## പണിയാൻ സഹായിക്കൂ

ഈ ഡാറ്റാബേസ് അത് ഉപയോഗിക്കുന്നവർക്കൊപ്പമാണ് വളരുന്നത്. നിങ്ങൾ സെർവറുകൾ, fail2ban, WAF അല്ലെങ്കിൽ സ്വന്തം ഹണിപോട്ടുകൾ നടത്തുന്നുണ്ടെങ്കിൽ, നിങ്ങളെ ആക്രമിക്കുന്നത് ഞങ്ങൾക്ക് അയക്കൂ, ഞങ്ങളത് പ്രസിദ്ധീകരിക്കാം: [ffraud.com/report](https://ffraud.com/report) ൽ അറിയിക്കുക, fail2ban നെ [തയ്യാറായ എൻഡ്‌പോയിന്റിലേക്ക്](https://ffraud.com/docs/contribute) തിരിക്കുക, അല്ലെങ്കിൽ ഇവിടെത്തന്നെ ഒരു issue തുറക്കുക. ഓരോ സമർപ്പണവും ഞങ്ങൾ പരിശോധിക്കുന്നു, ആവർത്തനങ്ങൾ നീക്കുന്നു, സ്കോർ നൽകുന്നു; സ്ഥിരീകരിച്ചവ അടുത്ത ബിൽഡിൽ, അതായത് അര മണിക്കൂറിനുള്ളിൽ, പുറത്തുവരും, വേണമെങ്കിൽ നിങ്ങളുടെ പേരോടെ.
