# โดเมนอีเมลใช้แล้วทิ้ง สร้างใหม่ทุก 30 นาที

<p align="center"><b>โดเมนอีเมลใช้แล้วทิ้งและชั่วคราว 219,530 รายการ รายการเดียวเรียบง่าย รีเฟรชตลอดทั้งวัน</b></p>
<p align="center"><sub>สัญญาอนุญาต MIT &middot; ไม่ต้องสมัคร ไม่ต้องใช้คีย์ API ไม่จำกัดจำนวนคำขอ &middot; อัปเดตเมื่อ 09.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/th.svg?v=1788975045" alt="ตรวจสอบที่อยู่ฟรีบน ffraud.com" width="540"></a></p>

กล่องจดหมายใช้แล้วทิ้งคือเส้นทางที่ทำให้บัญชีปลอมถูกผลิตขึ้นเป็นจำนวนมาก: สมัคร รับลิงก์ยืนยัน เผาโควตาฟรี แล้วทำซ้ำ นี่คือฐานข้อมูลอีเมลใช้แล้วทิ้งแบบเปิดที่อยู่เบื้องหลัง [ffraud.com](https://ffraud.com) รวมทุกโดเมนอีเมลชั่วคราวและใช้แล้วทิ้งที่เราหาเจอ ไว้ในไฟล์ข้อความไฟล์เดียว บริการใหม่ผุดขึ้นทุกวัน รายการนี้จึงถูกสร้างใหม่**ทุก 30 นาที** สิ่งที่คุณดึงไปยังมีชีวิตอยู่ในขณะนี้ ไม่ใช่ภาพนิ่งจากสัปดาห์ที่แล้ว ไม่ต้องสมัคร ไม่ต้องใช้คีย์ ไม่มีขีดจำกัด

## สรุปตัวเลข

- โดเมนอีเมลใช้แล้วทิ้งและชั่วคราว **219,530** รายการ บรรทัดละหนึ่งรายการ เรียงลำดับแล้ว พร้อมโหลดเข้า `Set` ได้เลย
- สร้างใหม่และเผยแพร่**ทุก 30 นาที** ประวัติ commit คือบันทึกการเปลี่ยนแปลง และ [`metadata.json`](metadata.json) เก็บเวลาสร้างที่แม่นยำไว้
- การตรวจจับไม่ได้หยุดอยู่แค่รายการนี้: เอนจินเบื้องหลัง [ffraud.com](https://ffraud.com) ยังรู้จักบริการใช้แล้วทิ้งจาก**โครงสร้างพื้นฐานทางอีเมล**ของมันด้วย จึงจับโดเมนที่เพิ่งเกิดใหม่ได้ตั้งแต่วันที่มันโผล่ขึ้นมา ก่อนที่รายการใดจะมีมันเสียอีก
- ผู้ให้บริการอีเมลกระแสหลักและแบบเสียเงินถูก**กันออกไป**โดยตั้งใจ เพื่อไม่ให้ลูกค้าตัวจริงที่ใช้โดเมนของตัวเองถูกเข้าใจผิดว่าเป็นบริการใช้แล้วทิ้ง
- **สัญญาอนุญาต MIT** รวมการใช้เชิงพาณิชย์ ไม่ต้องให้เครดิต
- ไฟล์ข้อความไฟล์เดียว ไม่มีไฟล์บีบอัด ไม่มีสคีมา ไม่มีไลบรารีฝั่งไคลเอนต์

## เริ่มใช้อย่างรวดเร็ว

```bash
# รายการทั้งหมด บรรทัดละหนึ่งโดเมน
curl -s https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/disposable-email-domains.txt
```

โหลดเข้า `Set` แล้วปฏิเสธส่วนโดเมนของที่อยู่ตั้งแต่ตอนสมัครสมาชิก ที่ขนาดเท่านี้ การค้นในหน่วยความจำแทบไม่มีต้นทุน และคุณสกัดบัญชีใช้แล้วทิ้งได้ก่อนที่มันจะไปถึงฐานข้อมูลของคุณด้วยซ้ำ

## ตรวจสอบทีละที่อยู่โดยไม่ต้องดาวน์โหลดอะไรเลย

คุณไม่จำเป็นต้องดาวน์โหลดรายการเพื่อตรวจสอบที่อยู่เดียว API สาธารณะไม่ต้องใช้คีย์และไม่มีเพดานต่อวัน:

```bash
# ข้อมูลครบถ้วนของ IP หนึ่งหมายเลข: คะแนน เหตุผล หมวดหมู่
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ที่อยู่นี้เป็นแบบใช้แล้วทิ้งหรือไม่
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# โดเมนนี้แจกกล่องจดหมายใช้แล้วทิ้งหรือเปล่า
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

สำหรับเอเจนต์และผู้ช่วยอัตโนมัติ: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) คือดัชนีสำหรับเครื่อง, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) คือเอกสารทั้งหมดในรูป Markdown ล้วน และ [ffraud.com/openapi.json](https://ffraud.com/openapi.json) คือข้อกำหนด OpenAPI ทั้งสามอย่างเปิดสาธารณะ ไม่ต้องใช้คีย์ และทำมาเพื่อให้ดึงไปใช้ได้โดยตรง ใครถนัดหน้าเว็บมากกว่า ใช้เครื่องมือตรวจสอบฟรีได้ที่ [ffraud.com/tools](https://ffraud.com/tools)

## รายการนี้สร้างขึ้นอย่างไร

สองสิ่งเป็นตัวสร้างมันขึ้นมา: เครือข่ายเซนเซอร์ honeypot ของเราเอง ซึ่งคอยเฝ้าดูว่าบริการใดกำลังแจกกล่องจดหมายใช้แล้วทิ้ง กับรายงานจากคนที่ฟอร์มสมัครสมาชิกถูกนำไปใช้ในทางมิชอบ ทุกโดเมนที่เข้าข่ายจะผ่านการตรวจสอบจากเอนจิน ffraud ก่อนถูกเผยแพร่

เอนจินยังรู้จักบริการใช้แล้วทิ้งจาก**โครงสร้างพื้นฐานทางอีเมลที่อยู่เบื้องหลัง**ด้วย ไม่ใช่แค่จากชื่อโดเมน ผู้ให้บริการเหล่านี้ซื้อโดเมนใหม่ไม่หยุด แต่ยังคงชี้พวกมันไปที่เมลเซิร์ฟเวอร์ไม่กี่ตัวเดิม โดเมนที่เพิ่งเกิดใหม่จึงถูกจดจำได้ตั้งแต่วันที่มันโผล่ขึ้นมา ก่อนที่มันจะเข้าไปอยู่ในรายการใด ๆ หลายสัปดาห์

เหตุผลเดียวกันนี้เองที่กันบริษัทตัวจริงออกจากรายการนี้ แพลตฟอร์มอีเมลที่ให้บริการคนทั่วไป ตั้งแต่ Google Workspace และ Microsoft 365 ไปจนถึง IONOS, Strato, GMX, Proton, Zoho และ iCloud ถูกกันออกโดยระบุชื่อ เพราะการที่บริการใช้แล้วทิ้งไปจอดโดเมนไว้ข้าง ๆ ลูกค้าตัวจริงอีกล้านราย ไม่ได้บอกอะไรเกี่ยวกับลูกค้าเหล่านั้นเลย ความระมัดระวังตรงนี้ทำให้เราพลาดการตรวจจับไปบ้าง ส่วนความสะเพร่าจะทำให้ใครสักคนเสียการสมัครสมาชิกจริงไปหนึ่งราย

</details>

<details>

</details>

## มาช่วยกันสร้าง

ฐานข้อมูลนี้เติบโตไปพร้อมกับคนที่ใช้มัน ถ้าคุณดูแลเซิร์ฟเวอร์ fail2ban WAF หรือ honeypot ของตัวเอง ส่งสิ่งที่โจมตีคุณมาให้เรา แล้วเราจะเผยแพร่ให้: รายงานที่ [ffraud.com/report](https://ffraud.com/report) ชี้ fail2ban ไปที่ [endpoint สำเร็จรูป](https://ffraud.com/docs/contribute) หรือเปิด issue ที่นี่ เราตรวจสอบ ตัดรายการซ้ำ และให้คะแนนทุกรายการที่ส่งเข้ามา สิ่งที่ยืนยันแล้วจะเข้าสู่การสร้างรอบถัดไป คือภายในครึ่งชั่วโมง พร้อมเครดิตชื่อคุณถ้าต้องการ

## ข้อมูลเปิดที่เกี่ยวข้อง

- **[ฐานข้อมูลการฉ้อโกงทาง IP](https://github.com/FFraud-com/ip-fraud-database)**: ฐานข้อมูลเปิดของเราที่รวบรวมที่อยู่ IP อันตรายซึ่งยืนยันแล้วและเครือข่ายที่ถูกใช้ในทางมิชอบสูง แต่ละรายการมีคะแนน หมวดหมู่ และการยืนยันอย่างเป็นอิสระ
