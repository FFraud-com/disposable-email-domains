# یک بار استعمال ای میل ڈومین، ہر 30 منٹ بعد دوبارہ تعمیر

<p align="center"><sub>MIT لائسنس &middot; رجسٹریشن نہیں، API کلید نہیں، درخواستوں کی حد نہیں &middot; تازہ کاری 10.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/tools/email-blacklist-check"><img src="https://raw.githubusercontent.com/FFraud-com/disposable-email-domains/main/assets/cta/ur.svg?v=1789054248" alt="ffraud.com پر ایک پتہ مفت جانچیں" width="540"></a></p>

پھینک دینے والے ان باکس ہی وہ راستہ ہیں جس سے بڑے پیمانے پر جعلی اکاؤنٹ بنائے جاتے ہیں: سائن اپ کرو، تصدیقی لنک اٹھاؤ، مفت حد جلا دو، پھر سے شروع۔ یہ [ffraud.com](https://ffraud.com) کے پیچھے کھڑا کھلا یک بار استعمال ای میل ڈیٹابیس ہے: ہر عارضی اور پھینک دینے والا میل ڈومین جو ہمیں مل سکا، ایک ہی متن فائل میں۔ نئی خدمات ہر روز نکلتی ہیں، اس لیے فہرست **ہر 30 منٹ بعد** نئے سرے سے بنتی ہے: آپ جو کھینچتے ہیں وہ اسی وقت زندہ ہے، پچھلے ہفتے کی تصویر نہیں۔ نہ رجسٹریشن، نہ کلید، نہ کوئی حد۔

## مختصراً

- **219,573** یک بار استعمال اور عارضی ای میل ڈومین، فی سطر ایک، ترتیب شدہ، سیدھا `Set` میں لادنے کے لیے تیار
- **ہر 30 منٹ بعد** نئے سرے سے بن کر شائع ہوتا ہے۔ کمٹ کی تاریخ ہی تبدیلیوں کا ریکارڈ ہے، اور [`metadata.json`](metadata.json) میں تعمیر کا درست وقت ہوتا ہے
- شناخت صرف فہرست پر نہیں رکتی: [ffraud.com](https://ffraud.com) کے پیچھے والا انجن یک بار استعمال خدمات کو ان کے **میل ڈھانچے** سے بھی پہچان لیتا ہے، اور یوں بالکل نیا ڈومین اسی دن پکڑ لیتا ہے جس دن وہ سامنے آئے، کسی فہرست میں آنے سے پہلے
- عام اور ادائیگی والے میل فراہم کنندگان جان بوجھ کر **باہر رکھے گئے ہیں**، تاکہ اپنے ڈومین پر بیٹھے اصلی گاہک کو کبھی یک بار استعمال خدمت نہ سمجھا جائے
- **MIT لائسنس**، تجارتی استعمال سمیت، حوالہ دینا لازمی نہیں
- ایک ہی متن فائل۔ نہ آرکائیو، نہ اسکیما، نہ کلائنٹ لائبریری


## کچھ ڈاؤن لوڈ کیے بغیر ایک پتہ جانچیں

ایک پتہ جانچنے کے لیے فہرست ڈاؤن لوڈ کرنے کی ضرورت نہیں۔ عوامی API کوئی کلید نہیں مانگتا اور اس کی روزانہ کوئی حد نہیں:

```bash
# ایک آئی پی کی مکمل معلومات: اسکور، وجہ، زمرے
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# کیا یہ پتہ یک بار استعمال کا ہے؟
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# کیا یہ ڈومین پھینک دینے والے میل باکس بانٹتا ہے؟
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

ایجنٹوں اور معاونین کے لیے: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) مشینوں کے لیے اشاریہ ہے، [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) میں پوری دستاویزات سادہ Markdown میں ہیں، اور [ffraud.com/openapi.json](https://ffraud.com/openapi.json) OpenAPI تفصیل ہے۔ تینوں عوامی ہیں، کوئی کلید نہیں مانگتے، اور براہِ راست حاصل کرنے کے لیے ہی بنے ہیں۔ جو صفحہ پسند کریں، ان کے لیے مفت جانچ کے اوزار [ffraud.com/tools](https://ffraud.com/tools) پر ہیں۔

## یہ فہرست کیسے بنتی ہے

دو چیزیں اسے بناتی ہیں: ہمارا اپنا شہد کے برتن والا سینسر نیٹ ورک، جو دیکھتا رہتا ہے کہ کون سی خدمات پھینک دینے والے میل باکس بانٹ رہی ہیں، اور ان لوگوں کی اطلاعات جن کے سائن اپ فارم کا غلط استعمال ہوا۔ شائع ہونے سے پہلے ہر ممکنہ ڈومین کو ffraud انجن جانچتا ہے۔

انجن یک بار استعمال خدمت کو صرف ڈومین کے نام سے نہیں بلکہ **اس کے پیچھے موجود میل ڈھانچے** سے بھی پہچانتا ہے۔ ایسی خدمات چلانے والے مسلسل نئے ڈومین خریدتے ہیں مگر انہیں انہی چند میل سرورز کی طرف موڑتے رہتے ہیں، چنانچہ بالکل نیا ڈومین بھی اسی دن پہچانا جا سکتا ہے جس دن وہ سامنے آئے، کسی فہرست میں پہنچنے سے ہفتوں پہلے۔

یہی دلیل اصل کمپنیوں کو اس فہرست سے باہر رکھتی ہے۔ عام لوگوں کو خدمت دینے والے میل پلیٹ فارم، Google Workspace اور Microsoft 365 سے لے کر IONOS، Strato، GMX، Proton، Zoho اور iCloud تک، نام لے کر باہر رکھے گئے ہیں، کیونکہ کوئی یک بار استعمال خدمت دس لاکھ اصلی گاہکوں کے پہلو میں ڈومین کھڑا کر دے تو اس سے ان گاہکوں کے بارے میں کچھ ثابت نہیں ہوتا۔ یہاں احتیاط ہمیں چند شناختوں سے محروم کرتی ہے؛ لاپروائی کسی کا ایک اصلی سائن اپ چھین لیتی۔
